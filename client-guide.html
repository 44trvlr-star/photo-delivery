写真の閲覧・ダウンロード方法

お送りしたURLを開くと、撮影した写真の一覧が表示されます。
1枚ずつ保存することも、まとめて全枚ダウンロードすることもできます。
1枚だけ保存

写真をタップして拡大 → 右下の↓ ボタンをタップ

全枚まとめて保存

ページ上部の「すべてダウンロード」ボタンをタップ

1枚ずつ保存する方法
  1. ギャラリーの写真をタップして大きく表示する
  2. 右下の ↓ ボタンをタップ
  3. Googleドライブのページが開くので、右上の ⋮ または 共有 をタップ
  4. 「ダウンロード」 を選択 → カメラロールに保存される
Googleドライブアプリがインストールされていると、よりスムーズにダウンロードできます（無料）。
全枚まとめてダウンロードする方法
  1. ページ上部（表紙）の 「すべてダウンロード」 ボタンをタップ
  2. Googleドライブのフォルダが開く
  3. 右上の ⋮ をタップ →「ダウンロード」を選択
  4. ZIPファイルがダウンロードされる（ファイルアプリに保存される）
  5. ファイルアプリを開き、ZIPをタップして解凍 → 写真が展開される
注意：ZIPファイルはカメラロールには直接保存されません。ファイルアプリで解凍後、写真を長押し →「写真に保存」でカメラロールへ移動できます。

全枚まとめて保存

ページ上部の「すべてダウンロード」ボタンをタップ

1枚ずつ保存する方法
  1. ギャラリーの写真をタップして大きく表示する
  2. 右下の ↓ ボタンをタップ
  3. Googleドライブのページが開く
  4. 右上の ⋮ をタップ → 「ダウンロード」 を選択
  5. 本体ストレージの ダウンロード フォルダに保存される
Googleドライブアプリがインストールされているとさらに簡単です（無料）。写真を開いた状態で右上の ⋮ →「ダウンロード」でOKです。
全枚まとめてダウンロードする方法
  1. ページ上部（表紙）の 「すべてダウンロード」 ボタンをタップ
  2. Googleドライブのフォルダが開く
  3. 右上の ⋮ をタップ → 「ダウンロード」 を選択
  4. ZIPファイルが ダウンロード フォルダに保存される
  5. ファイルマネージャーアプリでZIPを開いて解凍する
Googleドライブアプリを使う場合は、フォルダを長押し → 「ダウンロード」でZIPをまとめて取得できます。
