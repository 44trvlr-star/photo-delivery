Photo Delivery セットアップガイド

写真納品サイトをゼロから始める手順書
このガイドに沿って設定すると、クライアントに写真を納品するための専用サイトが作れます。
一度設定してしまえば、毎回の使い方はとてもシンプルです。費用は完全無料、難しい知識も不要です。

所要時間の目安：30〜60分（初回のみ）
はじめる前に
準備

必要なものを確認する

  • Googleアカウント（既存のものでOK。写真の保管と API に使います）
  • GitHubアカウント（無料。サイトの公開に使います。これから作ります）
  • delivery.html — クライアントが見るギャラリーページ
  • admin.html — URLを生成する管理画面
  • index.html — 自動リダイレクト用（変更不要）
💡 GoogleアカウントはGmailと同じアカウントです。すでにお持ちの場合はそのまま使えます。
セットアップ手順
STEP 1

GitHubアカウントを作る

  1. github.com をブラウザで開く
  2. 右上の「Sign up」をクリック
  3. メールアドレス・パスワード・ユーザー名を入力して登録する
  4. 届いたメールを開き、認証コードを入力して登録を完了する
⚠️ ユーザー名はURLの一部になります（例：ユーザー名.github.io）。英数字とハイフンで設定してください。
STEP 2

Google Drive APIキーを取得・保護する

APIキーとは「このサービスからGoogleドライブを読み込んでいいですよ」という許可証のようなものです。無料で取得できます。

  1. console.cloud.google.com を開く（Googleアカウントでログイン）
  2. 画面上部の「プロジェクトを選択」→「新しいプロジェクト」をクリック
  3. プロジェクト名に適当な名前（例：photo-delivery）を入力 → 「作成」
  4. 左メニューの「APIとサービス」→「ライブラリ」を開く
  5. 検索欄に Google Drive API と入力 → 表示された「Google Drive API」をクリック → 「有効にする」
  6. 左メニューの「APIとサービス」→「認証情報」を開く
  7. 上部の「＋ 認証情報を作成」→「APIキー」をクリック
  8. 画面に表示された英数字の文字列（例：AIzaSyXXXXXXXX...）をコピーして、メモ帳などに保存する
⚠️ APIキーはコードファイル内に書き込むため、次の「キーを制限する」手順が必須です。制限しないと第三者に不正利用されるリスクがあります。

APIキーにReferrer制限をかける（必須）

「このURLからのアクセスのみ許可する」という設定です。これをすることで、キーが知られても他のサイトからは使えなくなります。

  1. 認証情報のページで、作成したAPIキーの名前をクリックして編集画面を開く
  2. 「アプリケーションの制限」セクションで「HTTPリファラー（ウェブサイト）」を選択
  3. 「ウェブサイトの制限」の「＋ 項目を追加」をクリックし、以下の2行を追加する：
    https://あなたのユーザー名.github.io/* http://localhost/*
    ※ 2行目はローカルテスト用です。不要なら省略してもOKです
  4. 「API の制限」セクションで「キーを制限」を選択し、「Google Drive API」のみにチェックを入れる
  5. 「保存」をクリック
💡 制限設定が反映されるまで数分かかる場合があります。
STEP 3

delivery.html と admin.html にAPIキーを貼り付ける

2つのファイルにAPIキーを1箇所ずつ貼り付けます。手順はどちらも同じです。

Macの場合：

  1. delivery.html を右クリック →「このアプリケーションで開く」→「テキストエディット」を選ぶ
  2. テキストエディットが開いたら、上メニューの「フォーマット」→「標準テキストにする」をクリック
  3. Command + F で検索欄を開き、YOUR_API_KEY_HERE と入力して検索
  4. 以下の行が見つかります：
    const API_KEY = 'YOUR_API_KEY_HERE';
  5. YOUR_API_KEY_HERE の部分をコピーしたAPIキーに置き換える：
    const API_KEY = 'AIzaSyXXXXXXXX...';
  6. Command + S で保存する
  7. admin.html でも同じ手順を繰り返す（同じAPIキーを入れてください）

Windowsの場合：

  1. delivery.html を右クリック →「プログラムから開く」→「メモ帳」を選ぶ
  2. Ctrl + F で検索欄を開き、YOUR_API_KEY_HERE を検索
  3. 同様にAPIキーを貼り付けて保存する
  4. admin.html でも同じ手順を繰り返す
💡 2ファイルに同じキーを入れます。STEP 2でReferrer制限をかけてあれば、ソースコードに書いてあっても安全です。
STEP 4

GitHubにリポジトリを作ってファイルをアップロードする

「リポジトリ」とはファイルを入れる箱のことです。

  1. GitHubにログインし、右上の「＋」アイコン→「New repository」をクリック
  2. 「Repository name」に photo-delivery と入力
  3. 「Public」（公開）を選択する
  4. 「Create repository」をクリック
  5. 次の画面で「uploading an existing file」というリンクをクリック
  6. エクスプローラー（Mac はFinder）から以下の3ファイルをまとめてドラッグ＆ドロップ：
    • delivery.html（APIキーを貼り付け済みのもの）
    • admin.html
    • index.html
  7. 画面下部の「Commit changes」ボタンをクリック
💡 3ファイルを一度に選択してまとめてドロップしてください。
STEP 5

GitHub Pages を有効にしてサイトを公開する

  1. リポジトリのページ上部にある「Settings」タブをクリック
  2. 左メニューを下にスクロールして「Pages」をクリック
  3. 「Branch」の項目で None となっている部分を main に変更
  4. 「Save」をクリック
  5. 2〜5分待ってからページを更新すると、以下のURLが表示される：
    https://あなたのユーザー名.github.io/photo-delivery/
⚠️ 反映まで数分かかることがあります。すぐに開けない場合は少し待ってから再度試してください。
毎回の使い方

納品するときの手順

  1. 写真をGoogleドライブにアップロードする
    クライアントごとにフォルダを作り、納品する写真を入れる
  2. フォルダを「共有」設定にする
    フォルダを右クリック →「共有」→「リンクを知っている全員」→「閲覧者」に設定 → リンクをコピー
  3. 管理画面を開く
    https://あなたのユーザー名.github.io/photo-delivery/admin.html をブックマークしておく
  4. 情報を入力してURLを生成する
    • Google DriveのフォルダURL（コピーしたもの）
    • 案件名（クライアントの名前など）
    • 撮影日
    • 公開期限（デフォルトで30日後）
    • 合言葉（任意・設定するとパスワードが必要になる）
    • カバー写真の番号（何枚目をトップに表示するか。空欄なら1枚目）
    • タイトルフォント（英語タイトルはRaleway、日本語は明朝体かゴシックを選ぶ）
    • タイトルサイズ（S / M / L / XL）
    • 背景色
  5. プレビューで確認する
    フォルダURLを入力すると管理画面内にカバー写真のプレビューが表示されます。フォント・サイズ・タイトルをリアルタイムで確認できます。
  6. URLをコピーしてクライアントに送る
    「納品URLを生成する」ボタンを押して表示されたURLをコピーし、メールやLINEで送る
よくある質問
Q. 合言葉はどのくらい安全ですか？
合言葉はSHA-256というハッシュ関数で変換した値がURLに埋め込まれます。URLを見ても元の合言葉は分かりません。ただし、URLそのものはクライアントに渡すものなので、重要な情報を合言葉にするのは避けてください。
Q. 何枚まで対応できますか？
1フォルダあたり最大1,000枚まで対応しています。
Q. スマホでも見られますか？
はい。クライアントはスマホ・タブレット・PCどこからでも閲覧できます。
Q. 写真をダウンロードできますか？
はい。1枚ずつダウンロードするほか、「すべてダウンロード」ボタンからGoogleドライブのフォルダを開いてまとめてZIPダウンロードもできます。
Q. 公開期限が過ぎるとどうなりますか？
「公開期限が終了しました」というメッセージが表示され、写真を閲覧できなくなります。写真自体はGoogleドライブに残ります。
Q. Googleドライブのストレージは共有されますか？
いいえ。写真はそれぞれのGoogleアカウントのドライブに保存されます。他の人のストレージは使いません。
Q. ファイルを更新するにはどうすればいいですか？
GitHubのリポジトリページを開き、該当ファイルをクリック → 右上の鉛筆アイコンで編集、またはファイルを再アップロードしてください。
